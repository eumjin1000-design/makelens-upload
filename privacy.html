개인정보처리방침

「메이크렌즈 업로드」(이하 「이 앱」)는 운영자 본인의 유튜브 채널 관리를 위해 운영자 PC에서만 실행되는 개인용 도구입니다.

1. 받는 정보

구글 로그인 시 사용자가 동의한 범위의 접근 토큰과, 연결한 유튜브 채널의 이름·ID·썸네일 주소, 그리고 해당 채널의 영상 목록과 분석 수치(조회수·시청 시간·구독자 증감 등)를 받습니다.

2. 쓰는 목적

본인 채널에 영상을 업로드·예약하고, 분석 수치를 바탕으로 다음 영상 제작 방향을 정하는 데에만 씁니다. 광고·판매·프로파일링에 쓰지 않습니다.

3. 저장 위치와 기간

접근 토큰은 운영자 PC의 윈도우 자격 증명 관리자에만 저장되며, 외부 서버로 보내지 않습니다. 분석 수치는 운영자 PC의 로컬 파일에만 저장됩니다. 연결을 해제하거나 앱을 지우면 함께 삭제됩니다.

4. 제3자 제공

받은 정보를 제3자에게 팔거나 넘기지 않습니다. 구글 API 서비스로 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

5. 권한 철회

언제든지 구글 계정 › 보안 › 타사 앱 액세스에서 이 앱의 권한을 철회할 수 있습니다.
