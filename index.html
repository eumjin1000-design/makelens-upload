메이크렌즈 업로드

「메이크렌즈 업로드」는 운영자 본인이 소유한 유튜브 채널을 관리하기 위해 만든 개인용 데스크톱 도구입니다. 일반 사용자를 대상으로 하는 서비스가 아닙니다.

하는 일

  • 운영자가 직접 만든 영상을 운영자 본인 채널에 업로드하고 공개 예약을 합니다.
  • 썸네일·자막·재생목록을 설정합니다.
  • 운영자 본인 채널의 조회수·시청 시간 등 분석 수치를 읽어 다음 영상 제작에 참고합니다.

사용하는 구글 권한

  • YouTube Data API — 본인 채널 영상 업로드·관리
  • YouTube Analytics API — 본인 채널 분석 수치 읽기(읽기 전용)
